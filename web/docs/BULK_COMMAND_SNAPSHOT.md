# 일괄 명령 스냅샷

일괄창은 모든 선택 컨트롤러에 전송할 대표 명령값이다. 실행 시 표시된 1·2·3차 설정온도·편차·최저/최고환기와 장비 저온/고온 알람을 전체 전송한다. 현재값과 같아도 재전송할 수 있다.

- 채널별 첫 유효 설정은 초기 입력값으로만 사용한다.
- 전송 시 변경된 채널만 고르거나 대상별 기존 설정값을 섞지 않는다.
- 각 장비의 활성 채널에 해당 슬롯의 대표값을 그대로 복사한다. 주소·장비코드는 대상별로 유지한다.
- 현대 컨트롤러는 모든 채널+알람을 하나의 SET_CONTROLLER_SETTINGS 패킷/DB 행으로 묶는다. 채널 정보가 미수신이면 전송을 막고 full LIVE hydration을 요청한다.
- 오프라인 대상은 기존대로 제외하고 따로 표시한다.
- 성공은 DB 접수와 실제 장비 ACK를 구분한다. '접수14대'만으로 적용 성공을 판단하지 않는다.

검증 계약: 일괄창 확정값 = 컨트롤러별 payload.command_channels/alarms = 송신 wire 값 = 송신 이후 원시 업링크 설정값 = 패널 설정 표시.

회귀 검증은 서로 다른 설정을 가진14대에서 초기값 재전송 및 C환기만 편집했을 때에도 모든 A/B/C 필드가 대표값으로 동일하게 생성되는지 확인한다. 현장 검증은 배치별 ID로 원시 패킷과 화면을 대조한다.
