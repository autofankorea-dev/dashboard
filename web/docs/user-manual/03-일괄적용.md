# 3. 일괄적용

명령 권한(`canCommand`)이 있는 계정만 사용할 수 있습니다. 여러 축사·컨트롤러에 설정온도·알람 등을 한 번에 보냅니다.

## 선택 모드

![일괄적용 선택](./images/03-bulk-select.png)

### 이 화면에서 할 수 있는 것

- **일괄적용 토글**: 켜면 카드가 선택 모드로 바뀝니다. 끄면 일반 모니터링으로 돌아갑니다.
- **축사 / 유형 선택**: 적용할 임신사·분만사·자돈사 등을 체크합니다.
- **선택해제**: 선택을 모두 지웁니다.
- **설정입력**: 선택 후 개별 컨트롤러의 채널·알람 설정과 같은 카드가 열립니다.

## 설정 입력 · 적용

![일괄적용 모달](./images/03-bulk-modal.png)

### 이 화면에서 할 수 있는 것

- **현장 명령**: 카드 상단에, 선택한 컨트롤러에서 생성해 둔 설정값 칩이 있습니다. 칩을 누르면 그 채널 값이 표에 채워지고, 선택한 컨트롤러 전체로 보낼 수 있습니다. 표의 초깃값과 같아도 적용 버튼이 켜집니다. 저온·고온 경보는 칩에 없습니다. × 는 그 컨트롤러에 저장한 칩만 지웁니다.
- **채널 표**: 1차·2차·3차 행에 설정온도·편차·최저환기·최고환기가 칸으로 있습니다. 칸을 누르면 아래 공용 −/+ 로 그 값만 바꿉니다.
- **알람**: 저온·고온 경보도 같은 표 아래 칸입니다. 단위는 채널 설정과 같습니다. 설정온도는 **0.0~30.0℃**, 온도·편차·경보는 **0.1℃**, 환기는 **1%**입니다.
- **변경값 적용**: 값을 바꾼 채널과 알람, 또는 고른 설정값 칩의 채널만 선택한 컨트롤러로 나갑니다. 바꾼 값도 고른 칩도 없으면 버튼이 꺼집니다.
- **닫기**: 카드만 닫고 선택 모드는 유지합니다.

> **뷰어·명령 권한 없음**: 일괄적용 토글 자체가 보이지 않습니다.  
> 모바일에서도 같은 중앙 카드가 열립니다. → [08-모바일.md](./08-모바일.md)

적용이 나가면 일괄 선택 모드를 끄고, 해당 **컨트롤러 덮개** 가운데(온도·알람 띠 아래)에 채널별 세 단 게이지와 로딩 도넛이 붙습니다. DB에 적용 확인(`applied`)이 되면 체크가 나온 뒤 그 채널 줄은 사라집니다.
