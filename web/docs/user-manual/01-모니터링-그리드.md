# 1. 모니터링 — 필드 그리드

축사 배치와 이상 징후를 한눈에 보는 보기입니다.

판정 단위는 **컨트롤러 영향범위**입니다. 방을 칸으로 나눈 히트맵 탭은 쓰지 않습니다.

## 그리드 개요

![그리드 보기](./images/01-farm-grid.png)

### 이 화면에서 할 수 있는 것

- **필드 · 차트 전환**: 필드는 컨트롤러 카드, 차트는 추이(축사유형·축사번호)입니다. 우측 하단 **DELIN 뱃지**는 필드에서 권장 온·습 안내입니다(차트·목록에서는 숨김). → [11-모니터링-차트.md](./11-모니터링-차트.md) · [12-ARIA.md](./12-ARIA.md)
- **컨트롤러 카드**: 기본은 **정상·주의·위험 색 덮개**. 위는 축사유형명·축사번호·컨트롤러 번호, 가운데는 이탈 이유(지금 값·**알람 띠**), 아래는 판정. 값은 크게, 명칭·판정은 한 단계 낮고 조금 투명합니다. 격자는 순차 등장합니다. 누르면 덮개가 걷히며 명칭은 헤더로, 채움은 카드 테두리로 이어집니다. 지금 값·알람 띠는 온습 구간 테두리에 옅은 빛으로 남고, 덮개에 없던 습도(또는 온도) 막대는 이후에 나타납니다. 명칭을 다시 누르면 같은 모션이 거꾸로 재생되며 덮입니다. **설정에서 명령을 보내면 바로 덮개로 돌아와** 가운데에 채널별 진행(세 단 게이지·도넛)이 보입니다. 채점은 **사용자가 정한 온·습 알람 기준·편차**입니다(차트와 같은 값. 띠 안 가장자리는 주의, 띠 밖은 위험). 생육 권장은 우측 하단 **DELIN**이 안내합니다.
- **왼쪽 현황**: 그 축사에 속한 컨트롤러 중 가장 나쁜 알람 판정으로 면색을 칠합니다. 수신이 끊긴 카드만 연결 끊김입니다.
- **일괄적용**(명령 권한 있을 때): 토글을 켜면 덮개 없이 축사 선택 모드로 바뀝니다. → [03-일괄적용.md](./03-일괄적용.md)
- **범례**: 온도·습도·채널과 정상(초록)·주의(주황)·경고(빨강) 색 의미.
- **기간 선택 (24시간 / 7일 / 30일)**: 모든 축사 카드의 히트맵·그래프 기간이 함께 바뀝니다.
- **축사 카드**: 축사유형명과 **창고 아이콘+번호**, 현재 온도·습도, 상태(테두리). 왼쪽 위 손잡이(⠿)로 카드 위치를 옮기면 배치가 저장됩니다.
- **심각도 히트맵**: 세로 = 온도·습도·A·B·C, 가로 = 시간. **맨 오른쪽(최신)만** 현재 알람 상·하한으로 정상·주의·경고 색이 붙고, 과거 열은 이력(회색)입니다. 색이 진한 최신 구간을 클릭하면 상세가 열립니다.

## 확대 상세 — 컨트롤러별 그래프

![그리드 상세](./images/01-grid-detail.png)

### 이 화면에서 할 수 있는 것

- **지표 선택 (온도 / 습도 / 채널)**: 히트맵에서 고른 지표의 컨트롤러별 작은 그래프가 아래(또는 패널)에 펼쳐집니다.
- **점선(알람 상·하한)**: 상세 그래프의 참조선입니다. 히트맵·마커의 주의·경고는 **최신 값**만 현재 임계로 판정하며, 과거 구간을 소급하지 않습니다.
- **닫기**: 확대 상세를 접고 그리드만 봅니다.

> **뷰어**: 조회만 가능합니다. 일괄적용·설정 적용은 없습니다. → [09-역할별-차이.md](./09-역할별-차이.md)
