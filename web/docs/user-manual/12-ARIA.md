# 12. DELIN — 제거됨

DELIN(델린) 뱃지, 축사유형·일령별 권장 온·습 안내, 전용 탭은 제거되었습니다.

현재 환경 판단은 컨트롤러 공통 저온·고온 경보값입니다. 경보값이 없거나 유효하지 않으면 확인 필요이며, 권장값으로 대체하지 않습니다. 습도는 실측만 표시합니다.
