# 5. 헤더와 알람

오른쪽 상단 **도구 아이콘**과 **계정**으로 알림·기능·스타일을 다룹니다.

## 헤더 도구

아이콘이 헤더에 **상시** 보입니다. 알림·오프라인이 있으면 이상상황 배지가 표시됩니다.

순서(왼쪽 → 오른쪽, 계정 직전): **이상상황 · 운영(관리자) · 오늘의 리포트 · 라이트/다크 · PC/모바일(넓은 화면)**.

- **이상상황**: **모듈 에러코드** + **통신 두절** + **알람값 초과**(현장 기준±편차)를 종에 짧게 모읍니다. 현장 알람에 안 오른 값만 **권장 이탈**로 덧붙입니다. 누르면 목록이 펼쳐집니다.
- **확인**: 모듈 경보 행의 **확인**을 누르면 해당 경보가 활성 목록에서 빠집니다. (통신 두절·알람값 초과·권장 이탈 행에는 확인이 없습니다.)
- **운영**(관리자): 운영 ↔ 모니터링 전환.
- **오늘의 리포트**: 활성 농장 기준 PDF 다운로드. 표지는 진초록 레터헤드입니다. 구성은 **농장 30일(1시간)** → **축사유형마다 1장** → **마지막에 권장구간 이탈**입니다. 그래프는 온도·습도·채널을 각각 한 행으로 그립니다. 표지 상·하한은 **이 농장에 설정한 알람**이고, 축사유형·이탈 페이지는 **생육 권장**입니다. 그래프의 최저·최고도 함께 표시합니다. 이상상황은 **모듈 에러·통신 두절**만 PDF에 넣고, 온·습 알람값 초과·권장 이탈은 종·델린에서 봅니다. 인쇄 그래프는 **30일·1시간**입니다(화면 미니 2시간·드래그줌 15분은 넣지 않습니다).
- **라이트 / 다크**: 화면 밝기 전환(이 기기에 저장).
- **PC / 모바일 레이아웃**: 넓은 화면에서만 미리보기 수동 전환(자동 감지 해제). 좁은 화면·실기기에서는 숨깁니다.

> 예전 독립 `/alarms` 화면은 없으며, 헤더 도구와 모니터링에서 통합 확인합니다.  
> 차트·목록에 보이는 온·습 알람은 **기준값±편차** 이며, 종 이상상황의 **알람값 초과**와 같습니다. 권장 숫자는 알람으로 저장하지 않습니다.  
> **델린**은 종에 올라온 같은 목록을 해설합니다. 적용·명령은 하지 않습니다.  
> **기기 알림:** 문자·전화가 아니라, 대시보드를 **앱으로 설치**한 뒤 **푸시 알림**으로 받을 예정입니다 (구현 후속).

## 계정 메뉴

![계정 메뉴](./images/05-header-account.png)

### 이 화면에서 할 수 있는 것

- **이름 · 이메일 · 역할**: 현재 로그인 계정과 관리자/운영자/뷰어를 확인합니다.
- **전국 관제 요약**: 농장을 고르지 않은 관리자 화면에서는 아이콘+숫자로 전체·정상·경보·오프라인·위치만을 봅니다.
- **기능 안내**: 헤더 물음표. 농장 모니터링에서 누르면 **현재 탭**(필드·차트) 안내가 다시 실행됩니다.
- **최근 활동**: 최근 명령·상태 요약(표시되는 경우).
- **농장 주소**: 주소 검색·저장. 운영자 등 명령 권한이 있는 계정, 그리고 관리자가 **특정 농장** 화면에 들어간 뒤에 해당 농장 주소를 고칩니다. 전국 관제 화면에서는 주소를 고치지 않습니다.
- **로그아웃**: 시트 오른쪽 위. 시트를 닫으려면 계정 뱃지·바깥·Esc를 씁니다.
