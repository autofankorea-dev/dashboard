# 4. 컨트롤러 설정

단건 컨트롤러의 알람·설정온도·편차를 보거나 적용합니다. 목록의 **설정** 모드 또는 카드의 설정 버튼으로 엽니다.

## 목록 — 설정 모드

![목록 설정 모드](./images/04-list-settings-mode.png)

### 이 화면에서 할 수 있는 것

- **설정 모드 탭**: 각 카드에 채널 A·B·C 숫자와 알림 한 줄, **기본값** / **명령 적용**(또는 **알림 저장**)이 보입니다.
- **한눈에 표**: 채널 세 줄과 알림 기준이 항상 보입니다. 줄을 누르면 그 층만 칸이 열립니다. 없는 채널은 **없음**입니다. 설정이 열리면 카드 상단 온·습도·채널 게이지는 접힙니다.
- **기본값**: 지금 고른 층(명령 또는 알림)의 입력을 되돌립니다.
- **명령 적용**: 바뀐 채널만 활성화됩니다. 누르면 **명령을 보낼까요?** 카드에서 대상·현재값·보낼 값을 확인한 뒤 **보내기**를 눌러야 전송됩니다. 취소하면 값은 유지되고 명령은 나가지 않습니다. 보낸 뒤 **적용한 값이 바로 표시**되며, 통신이 연결된 컨트롤러에는 곧 반영됩니다.
- **알림 저장**: 온도·습도 알림 기준만 저장합니다. 현장 컨트롤러로 나가지 않습니다.
- **오프라인**: 값이 `—`이거나 적용이 막힐 수 있습니다. 연결 상태를 먼저 확인하세요.

## 설정 패널 (펼침)

![설정 패널](./images/04-list-settings-panels.png)

![설정 펼침 예시](./images/04-settings-expanded.png)

### 이 화면에서 할 수 있는 것

- **채널 A / B / C**: 표에서 세 채널 숫자를 한눈에 봅니다. 줄을 눌러 값을 맞춘 뒤 **명령 적용**하면 바뀐 채널만 한 번에 보냅니다. 다른 채널 줄은 그대로 보입니다. 각 채널의 **실시간 장비코드**가 있으면 그대로 싣고, 없어도 채널 명령은 나갑니다. 채널 이름으로 장비코드를 추정하지 않습니다.
- **알람**: 온·습 **기준값·편차**. 온도는 **0.1℃**, 습도는 **1%** 단위. 차트 왼쪽 기준·녹색 구간과 같은 값입니다. **알림 저장**은 안내 기준이며 현장 명령이 아닙니다.
- **설정온도 · 편차**: 설정온도는 **0.0~30.0℃**(0.1℃). B·C 채널 값은 A 설정온도에 더해져 동작합니다. 온도편차는 **0.1℃** 단위(최소 0.5℃). 환기 최저·최고는 **1%** 단위.
- **조회 전용**(뷰어): 상단에 조회 전용 안내가 뜨고 입력·적용이 잠깁니다.
