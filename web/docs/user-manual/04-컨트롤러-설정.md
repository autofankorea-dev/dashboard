# 4. 컨트롤러 설정

단건 컨트롤러의 알람·설정온도·편차를 보거나 적용합니다. 목록의 **설정** 모드 또는 카드의 설정 버튼으로 엽니다.

## 목록 — 설정 모드

![목록 설정 모드](./images/04-list-settings-mode.png)

### 이 화면에서 할 수 있는 것

- **설정 모드 탭**: 각 카드에 채널 A·B·C 숫자와 알림 한 줄, **기본값** / **명령 적용**이 보입니다. 알림은 줄을 눌러 연 카드에서 저장합니다.
- **한눈에 표**: 채널 세 줄과 알림 한 줄이 항상 보입니다. 「현장 명령」 아래 칩은 그 카드의 표를 채웁니다. 칩을 눌러도 현장으로 나가지 않고, **명령 적용**이 전송입니다. **생성**은 가운데 카드에서 이름과 A·B·C 설정·편차·환기를 맞춘 뒤 이 기기 칩으로 남기고 표를 채웁니다. 채널은 우물 면으로 나뉩니다. 생성 카드는 설정·편차 **0.1℃**, 환기 **5%**이며 −/+를 누르면 한 칸, 꾹 누르면 연속입니다. × 는 칩만 지웁니다. 생성·삭제 확인에서 **Enter**는 진행, **Esc**는 취소입니다. 줄을 누르면 화면 한가운데에 **같은 −/+ 카드**가 뜹니다. 행 편집은 환기 **1%**입니다. 없는 채널은 **없음**입니다. 설정이 열리면 카드 상단 온·습도·채널 게이지는 접힙니다.
- **기본값**: 지금 표에 올라온 명령 입력을 되돌립니다.
- **명령 적용**: 바뀐 채널만 활성화됩니다. 누르면 **명령을 보낼까요?** 카드에서 대상·현재값·보낼 값을 확인한 뒤 **보내기**를 눌러야 전송됩니다. 취소하면 값은 유지되고 명령은 나가지 않습니다. 보낸 뒤 설정은 열린 채이고, 보낸 채널 줄이 왼쪽부터 접수·전송·확인으로 찹니다. 확인되면 체크가 잠깐 보인 뒤 색이 빠집니다. **적용한 값은 바로 표시**되며, 통신이 연결된 컨트롤러에는 곧 반영됩니다.
- **알림 저장**: 알림 줄을 눌러 연 카드에서 온도·습도 기준만 저장합니다. 현장 컨트롤러로 나가지 않습니다.
- **오프라인**: 값이 `—`이거나 적용이 막힐 수 있습니다. 연결 상태를 먼저 확인하세요.

## 설정 패널 (펼침)

![설정 패널](./images/04-list-settings-panels.png)

![설정 펼침 예시](./images/04-settings-expanded.png)

### 이 화면에서 할 수 있는 것

- **채널 A / B / C**: 표에서 세 채널 숫자를 한눈에 봅니다. 줄을 누르면 화면 중앙 카드에서 −/+로 값을 맞춘 뒤 **반영**하고, 패널의 **명령 적용**으로 바뀐 채널만 한 번에 보냅니다. 다른 채널 줄은 그대로 보입니다. 각 채널의 **실시간 장비코드**가 있으면 그대로 싣고, 없어도 채널 명령은 나갑니다. 채널 이름으로 장비코드를 추정하지 않습니다.
- **알람**: 온·습 **기준값·편차**. 온도는 **0.1℃**, 습도는 **1%** 단위. 차트 왼쪽 기준·녹색 구간과 같은 값입니다. **알림 저장**은 안내 기준이며 현장 명령이 아닙니다.
- **설정온도 · 편차**: 설정온도는 **0.0~30.0℃**(0.1℃). B·C 채널 값은 A 설정온도에 더해져 동작합니다. 온도편차는 **0.1℃** 단위(최소 0.5℃). 환기 최저·최고는 **1%** 단위.
- **조회 전용**(뷰어): 상단에 조회 전용 안내가 뜨고 입력·적용이 잠깁니다.
