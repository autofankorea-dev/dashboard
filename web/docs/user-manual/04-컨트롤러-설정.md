# 4. 컨트롤러 설정

단건 컨트롤러의 알람·설정온도·편차를 보거나 적용합니다. 목록의 **설정** 모드 또는 카드의 설정 버튼으로 엽니다.

## 목록 — 설정 모드

![목록 설정 모드](./images/04-list-settings-mode.png)

### 이 화면에서 할 수 있는 것

- **설정 모드 탭**: 각 카드에 알람·설정온도 요약과 **기본값** / **적용**이 보입니다.
- **알람 / 설정온도 · 편차 접기**: 요약 줄을 눌러 상세 입력을 펼칩니다.
- **기본값**: 입력 중인 변경을 되돌립니다.
- **적용**: 변경이 있을 때만 활성화됩니다. 누르면 **명령을 보낼까요?** 카드에서 대상·현재값·보낼 값을 확인한 뒤 **보내기**를 눌러야 전송됩니다. 취소하면 값은 유지되고 명령은 나가지 않습니다. 보낸 뒤 **적용한 값이 바로 표시**되며, 통신이 연결된 컨트롤러에는 곧 반영됩니다.
- **오프라인**: 값이 `—`이거나 적용이 막힐 수 있습니다. 연결 상태를 먼저 확인하세요.

## 설정 패널 (펼침)

![설정 패널](./images/04-list-settings-panels.png)

![설정 펼침 예시](./images/04-settings-expanded.png)

### 이 화면에서 할 수 있는 것

- **온도·습도 게이지**: 현재값과 허용 범위를 한눈에 봅니다.
- **채널 A / B / C**: 채널별로 값을 맞춘 뒤 **적용**하면 바뀐 채널만 한 번에 보냅니다. 탭을 바꿔도 입력 중인 값은 유지됩니다. 각 채널의 **실시간 장비코드**가 있으면 그대로 싣고, 없어도 채널 명령은 나갑니다. 채널 이름으로 장비코드를 추정하지 않습니다.
- **알람**: 온·습 **기준값·편차**. 온도는 **0.1℃**, 습도는 **1%** 단위. 차트 왼쪽 기준·녹색 구간과 같은 값입니다.
- **설정온도 · 편차**: 설정온도는 **0.0~30.0℃**(0.1℃). B·C 채널 값은 A 설정온도에 더해져 동작합니다. 온도편차는 **0.1℃** 단위(최소 0.5℃). 환기 최저·최고는 **1%** 단위.
- **조회 전용**(뷰어): 상단에 조회 전용 안내가 뜨고 입력·적용이 잠깁니다.
