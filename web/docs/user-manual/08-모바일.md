# 8. 모바일 핵심 차이

PC와 기능은 같고, 배치만 다릅니다. 헤더의 **레이아웃 토글**로 모바일 미리보기를 켜거나, 실제 좁은 화면에서 동일 UI가 적용됩니다.

## 홈 · 하단 내비

![모바일 홈](./images/08-mobile-home.png)

### 이 화면에서 할 수 있는 것

- **하단 내비 (모니터링)**: 주 화면으로 돌아가는 고정 메뉴입니다.
- **필드 · 차트**: PC와 같은 보기 전환. 차트는 축사유형·축사번호 칸입니다.
- **일괄적용 · 기간**: 상단 툴바에 유지됩니다.
- **헤더 아이콘**: 연결·알람·계정은 아이콘 위주로 압축됩니다(이름·로그아웃 문구는 줄어들 수 있음).

### 손동작 (탭 · 스와이프 · 드래그)

PC의 클릭·휠과 달리, 모바일은 **한 손가락 탭 / 더블탭 / 세로·가로 슬라이드**로 조작합니다.

- **필드**: 카드를 **탭**하면 컨트롤러 시트가 열립니다. 목록은 **세로로 밀어** 스크롤합니다.
- **차트**: 축사유형·축사번호 평균 칸이며 최근 30일입니다. 목록 칸은 날짜·축 글자 없이 선만 봅니다. 축사를 펼친 카드에서 **핀치**하면 기간이 바뀝니다(오른쪽은 지금). ON/OFF 아이콘 묶음은 화면 너비에 맞춰 줄어듭니다. 좌·우 온·습 숫자는 띠 **가장자리**에 둡니다. 플롯을 **탭**하면 점이 핀되고 기준 칩이 낮아지며, 알람 **기준** 숫자나 상·하한선을 **더블탭**하면 값을 고칩니다. 컨트롤러 명령은 차트에서 보내지 않습니다.

## 컨트롤러 설정 sheet

![모바일 설정 sheet](./images/08-mobile-controller-sheet.png)

### 이 화면에서 할 수 있는 것

- **하단(또는 전면) sheet**: PC의 인라인 패널 대신 sheet로 설정·그래프가 열립니다. 시트 안 그래프는 현장과 같이 **선만** 그리고, 선을 누르면 핀·카드가 붙습니다.
- **축사·컨트롤러 표시**: PC는 아이콘 우하단에 번호가 겹칩니다. 모바일은 **아이콘과 번호를 나란히**, 아이콘 24px·숫자 16px로 둡니다. 시트 제목·상단 피커·현황 카드가 같은 방식입니다.
- **컨트롤러 / 설정** 탭: 추이 그래프와 설정 입력을 전환합니다.
- **알람 · 설정온도 · 편차 접기**: PC 목록 설정과 같은 두 묶음입니다.
- **기본값 / 적용**: 명령 권한이 있을 때만 적용이 가능합니다.
- **차트로 옮기기**: 차트 탭으로 이동하고, 그 컨트롤러 그래프가 **펼쳐집니다**. 다른 컨트롤러를 다시 옮기면 그 대로 바뀝니다.

## 일괄적용 bottom sheet

모바일에서 일괄적용 → 축사 선택 → **설정입력**을 누르면 PC 모달 대신 **하단 sheet**가 열립니다.

### 이 화면에서 할 수 있는 것

- **제어 채널 A / B / C**: PC와 동일. 탭으로 채널별 값을 맞춘 뒤 적용합니다.
- **설정온도 · 편차 / 알람** 접기 묶음: 한 손 조작에 맞게 세로로 쌓입니다.
- **N대 · 명령 M건 적용**: 대상·채널을 반영한 건수 표시.
- **취소 / 닫기**: sheet만 닫고 선택 모드는 유지할 수 있습니다.

> PC 일괄적용 UI 설명은 [03-일괄적용.md](./03-일괄적용.md)를 참고하세요.
